# 开发随手记总览

> 本区收录的是开发过程中真实遇到的"填坑"记录：零散、具体、以解决问题为导向，和成体系的知识章节互为补充。每篇都从一个具体需求或故障出发，给出可复用的做法。

## 这区是什么

和按知识体系组织的专题文档不同，"随手记"记录的是**实践中踩过的坑**：某个场景怎么实现、某个报错怎么排查、某个第三方库怎么用。它的价值在于"下次再遇到时能直接抄作业"。

内容大致分为几类：

- **工程打包/部署**类：本地打包成可交付文件、读取打包后的资源；
- **功能实现**类：导出、图表、指纹登录、防自动填充等具体功能；
- **Java 语言细节**类：创建对象的方式、反射的用法等。

## 怎么用这区

- 把它当**速查手册**：遇到相似场景先在本区搜关键词，再看专题文档补原理；
- 速查解决"怎么做"，专题解决"为什么"：例如 [Java 创建对象的四种方法](./dev-usage-newObj.md) 关注用法，而对象的类加载与初始化机制属于 JVM 知识；
- 记录原则：只写**验证过**的步骤和命令，附上关键代码与报错信息，方便日后复现。

::: tip 与专题文档的分工
随手记负责"点"（单个问题的解法），专题文档负责"面"（成套知识）。两者交叉引用，形成"问题 → 定位 → 原理"的闭环。
:::
