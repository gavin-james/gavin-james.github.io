# 设计模式速查总览

> 一句话意图：把 GoF 23 种设计模式压缩成「意图 + 结构 + 代码 + 辨析」的速查卡，用于面试前快速回想、写代码时快速比对。

本区是**速查**，追求一眼看懂、能立刻回忆；完整推导、UML 类图与 Java 源码级剖析见「设计模式 · 详解」分组。两套内容一一对应，可对照阅读。

## 学习路径

1. **先懂原则**：单一职责、开闭、里氏替换、依赖倒置、接口隔离、迪米特、合成复用，是模式背后的判断标准。
2. **按创建 → 结构 → 行为推进**：创建型解决「怎么造」，结构型解决「怎么搭」，行为型解决「怎么分工」。
3. **成对辨析**：工厂方法 vs 抽象工厂、策略 vs 状态、装饰器 vs 代理 vs 适配器、外观 vs 中介者，重点记「区别」一栏。
4. **回看 JDK/框架**：`Runtime`、`Collection.iterator()`、`InputStream` 装饰、Spring `ApplicationEvent`、AOP 动态代理，都是活例子。
