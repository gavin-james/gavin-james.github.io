# 关于本站

> Gavin James 的个人技术知识库，把日常学习与工程实践中散落的知识，整理成一套可持续维护、可检索的体系。

## 这是什么

本站是一个以 **Java 后端**为主线、向外延伸到数据库、框架、架构、前端与研发工具的个人知识库。内容以「专题正文 + 可运行示例」为主，目标不是搬运文档，而是把每个知识点讲成**能直接用于工作**的形态。

## 内容范围

| 分区 | 覆盖内容 |
|------|----------|
| [Java](/java/) | 基础、集合、并发、IO、JVM、新特性 |
| [数据库](/db/) | 数据库原理、SQL、MySQL、Redis、MongoDB、Elasticsearch |
| [开发](/develop/) | 开发理论、规范、设计模式、重构、质量保障、算法与数据结构 |
| [框架](/framework/) | Spring 生态（IoC/AOP/MVC/Boot/Cloud/Security）、ORM、消息队列、Web 容器 |
| [架构](/architecture/) | 分布式、微服务、高并发 |
| [前端](/front/) | HTML、CSS、JavaScript、Vue、React |
| [工具](/tool/) | Git、Maven、Gradle、Linux、Docker、Jenkins、IDE |

## 技术栈

- 静态站点框架：**VuePress 2** + [vuepress-theme-hope](https://theme-hope.vuejs.press/)
- 搜索：slimsearch；代码高亮：Shiki；图表：Mermaid、ECharts、Chart.js、Flowchart
- 部署：GitHub Pages（配合 CI 自动构建）

## 写作与版权

- 正文为个人整理与自写，力求准确；受认知与时效限制，可能存在疏漏，**关键结论请以官方文档为准**。
- 引用的第三方内容会尽量标注来源；如涉及版权问题，可通过站点仓库提 Issue 联系。

## 如何阅读

- 顶部导航按「Java / 数据库 / 开发 / 框架 / 架构 / 工具 / 前端」分区，左侧侧边栏是该分区的完整目录。
- 右上角搜索框支持站内全文检索。
